🏈 One-Time Firebase Setup

Greek Gridiron uses a free Firebase database so every brother sees live checklist updates. Takes about 5 minutes — only one person needs to do this.

  1. Go to console.firebase.google.com and sign in with a Google account
  2. Click Add Project → name it greek-gridiron → disable Google Analytics → Create Project
  3. In the left sidebar, click Firestore Database → Create database → choose Start in test mode → select us-central1 → Enable
  4. Click the ⚙️ gear icon (top-left) → Project settings → scroll to Your apps → click the </> web icon → register app (any nickname) → copy the firebaseConfig shown
  5. Open index.html and replace the placeholder config block near the top of the <script> section with your copied config, then re-deploy to GitHub Pages
// Find this block and replace it: const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_PROJECT_ID.appspot.com", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };

After setup, share the GitHub Pages URL with your chapter. Checkboxes sync in real-time for everyone. Firebase free tier handles this easily — no cost.

Tournament Structure

Bracket Format

  • 8 teams: 2 pools of 4 → top 2 from each advance → semifinals → championship
  • 10–12 teams: 3 pools (3–4 teams each) → top teams advance → quarterfinals → semis → championship

Game Format

  • Pool play: 20-minute halves, running clock
  • Playoffs: 25-minute halves
  • Championship: 30-minute halves
  • Hard stop: all play and ceremony must wrap by 9:30 PM — Stillwater 10 PM noise ordinance

OSU hosted the 2023 NIRSA Flag Football National Championship — Colvin staff are experienced with multi-field tournament logistics.

Sorority Involvement

OSU has 12 Panhellenic sororities and 13 established homecoming fraternity-sorority pairs — a ready-made framework for sorority involvement.

  • Banner Competition: Each sorority paired with a competing fraternity creates a banner; judged by a neutral party
  • "Greek Goddess" Spirit Award: Awarded to the sorority with the best overall crowd energy, cheering, and spirit throughout the day — adds real incentive beyond the banner comp
  • Homecoming Pairing Hook: Lean into existing homecoming pairings so each sorority is naturally cheering for "their" team
  • Ticket Sales: Sorority chapters purchase ticket blocks; drives revenue and crowd energy
  • Concession Volunteers: Option to involve sorority members in running the Dirty Soda/Snowcone booth

Concessions

  • Dirty Soda bar — high margin, easy to run
  • Snowcone machine
  • Stick to 2–3 items max — simplicity is the priority
  • Assign 2–3 volunteers to run the booth all day

Tradition & Trophy

  • Commission a football-shaped traveling trophy, engraved annually with the winning house
  • Winning house holds the trophy until the following year's event
  • Frame this prominently in all outreach — makes the $200 entry feel meaningful beyond the donation

Contracts & Registration

  • Base on Beta's King of the Court contract — modify for 7v7 flag football rules, liability, and conduct
  • All participating houses sign before their team is confirmed
  • Contract must include: roster submission deadline, code of conduct, forfeiture/no-show policy, entry fee payment deadline
  • Early-bird deadline: ~Sept 5 for $175 rate; $200 after
